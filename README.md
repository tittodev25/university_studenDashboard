# university_studenDashboard

Interactive data analysis dashboard for university student statistics, created by:
BRANDON VILLA and ARTURO MENDOZA

## Project Overview

This project was developed using:

- Python
- Google Colab
- Pandas
- Plotly
- Streamlit

The dashboard allows users to:

- Analyze university application trends
- Explore enrollment statistics
- Visualize retention rates
- Review student satisfaction metrics
- Interact with dynamic charts

---

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly

## Running the Project Locally

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the Streamlit dashboard:

```bash
streamlit run app.py
```
